## Stack Tecnológico

| Capa | Tecnología | Versión |
|------|-----------|---------|
| Backend | Kotlin + Spring Boot | 3.4.x |
| ORM | JPA / Hibernate + Flyway | - |
| DB | PostgreSQL | 16 |
| Auth | JWT (jjwt) + BCrypt | 0.12.x |
| Android | Kotlin + Jetpack Compose | - |
| DI | Koin | 4.x |
| Networking | Ktor Client | 3.x |
| UI | Material Design 3 | - |
| Infra | Docker + Nginx | - |
| CI/CD | GitHub Actions | - |
